# The Draw files

`app/`, `components/`, `public/`, and `data/draws.json` make up the live site. `draw.py` reads the root `word_wall.json`, the runtime word pool. `publish.py` handles publication. Read `INTENT.md` for the writing project's purpose and `STATUS.md` for current work.

`_docs/word-pool-sources/` preserves the original and working Word Wall spreadsheets. `_docs/previews/` preserves the standalone HTML preview and its screenshot. `_docs/THE-DRAW-VISION.md` and `_docs/WORD-LENS-FRAMEWORK.md` are supporting reference.
